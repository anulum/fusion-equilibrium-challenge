# Security policy

This repository is the permanent record of one competition entry. It receives corrections to its documentation and,
if the organisers ask for a rebuild, to its reproduction path; it has no release line with security support.

To report a security issue (for example a dependency in the pinned environments, or anything in the code that reads
untrusted files unsafely), use a [private security advisory](https://github.com/anulum/fusion-equilibrium-challenge/security/advisories/new)
or write to protoscience@anulum.li with the subject `[SECURITY] fusion-equilibrium-challenge`. Please do not open a
public issue for it. We acknowledge reports within 48 hours.
